# SLAI Writer
Smart software for writing powered by SLAI

When saving a document from SLAI Writer, the file gets the .sdoc extension by default. The user can choose to save it in other formats.

SLAI Writer is meant for professionals looking for easy-to-use, safe, and intuitive software to use with a built-in grammar assistant.

SLAI Writer is meant to be cloned inside SLAI/applications/slai_writer/
The entry module (run_slaiwriter.py) should be moved to the SLAI root directory.
